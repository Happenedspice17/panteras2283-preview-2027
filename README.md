# Forja · Panteras 2283

Sistema de temporada propio y gratuito para el equipo FRC Panteras 2283: kickoff con método, objetivos y cronograma, calendario, BOM/inventario (con importación desde Onshape), presupuesto por área, roles con titular y suplente, prácticas de aprendizaje por área y nivel, formación e inducción de seguridad, asesorías documentadas, eventos (logística, pits, partidos, scouting), memoria del equipo y reporte a patrocinadores.

Stack: React + Vite + TypeScript, Supabase (Postgres + RLS + Auth Google), GitHub Pages.

- Instalación: [docs/INSTALACION.md](docs/INSTALACION.md)
- Guía de sitios FIRST/FRC y Onshape: [docs/RECURSOS_FIRST.md](docs/RECURSOS_FIRST.md)

Roles: `coach` (todo), `lider` (alumno líder de área, edita), `alumno`, `mentor` (asesorías), `patrocinador` (solo reporte agregado), `pendiente` (sin acceso hasta aprobación).
